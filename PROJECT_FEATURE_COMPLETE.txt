HOW TO USE
================================================================================

1. ACCESS PROJECTS PAGE
   Open: http://localhost:8080/projects

2. QUICK LINK ACCESS
   - Click GitHub icon on project card → Opens repo in new tab
   - Click Live Demo icon on project card → Opens site in new tab

3. DETAILED VIEW
   - Click anywhere on project card → Navigates to detail page
   - URL changes to: http://localhost:8080/projects/{projectId}

4. VIEW RESOURCES
   - Scroll to "Resources" section on detail page
   - Click GitHub Repository → Opens in new tab
   - Click Live Demo → Opens in new tab

5. EXPRESS INTEREST
   - On detail page, click "Express Interest" button
   - (Requires login)

6. CONTACT SELLER
   - On detail page, click "Contact Seller" button
   - (Requires login and verification)
