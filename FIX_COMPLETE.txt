PROBLEM STATEMENT
───────────────────────────────────────────────────────────────────────────

Component: AdminExchangesPage.tsx
Error Type: TypeError
Message: Cannot read properties of null (reading 'name')
Severity: Critical (Crashes Admin Panel)
Location: Line 147 (initially)


ROOT CAUSE
───────────────────────────────────────────────────────────────────────────

When a user is deleted from the database:
  1. Their exchanges remain in the database
  2. The exchange still has a reference to the deleted user
  3. Backend populate() returns null for deleted user references
  4. Frontend code tried to access .name on null object
  5. Result: Unhandled TypeError crash


SOLUTION APPLIED
───────────────────────────────────────────────────────────────────────────

Added null safety guards to all property accesses:

Pattern Used:
  {variable && typeof variable === "object" ? variable.property : "Fallback"}

This pattern:
  ✓ Checks if variable exists
  ✓ Verifies it's an object type
  ✓ Safely accesses the property
  ✓ Provides fallback value if null/undefined
