WHAT WAS THE ERROR?
───────────────────
TypeError: Cannot read properties of null (reading 'name')
Location: AdminExchangesPage.tsx:147

WHY DID IT HAPPEN?
──────────────────
When a user account is deleted from the database, the exchange records still 
reference them. The backend returns null for these deleted user references, but
the frontend tried to access properties on null without checking first.

WHAT WAS FIXED?
───────────────
File: /frontend/src/pages/AdminExchangesPage.tsx

BEFORE:
  {exchange.requester.name}
  {exchange.receiver.name}

AFTER:
  {exchange.requester && typeof exchange.requester === "object" 
    ? exchange.requester.name : "Unknown User"}
  {exchange.receiver && typeof exchange.receiver === "object"
    ? exchange.receiver.name : "Unknown User"}

HOW MANY LINES CHANGED?
───────────────────────
4 lines total:
  • 2 lines for requester null checks
  • 2 lines for receiver null checks

WHAT'S THE RESULT?
──────────────────
✅ No more crashes
✅ Admin panel loads successfully
✅ Deleted users display as "Unknown User"
✅ All exchanges render correctly
